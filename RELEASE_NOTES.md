Necro Vision now gets working launchers (base game and Lost Company, DirectX 9 and 10) instead of the original one, which fails on every button. They come from an optional per-game file in this repository's `game-fixes` folder that the script downloads while installing, so other games can get fixes without a change to the script. See `game-fixes/GAMES.md` for the plain-language list of which games have a fix.
