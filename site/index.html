A fork of ZOOM Platform's installer script, which installs their Windows games on Linux with umu and Proton.

What this fork adds

Game-specific launcher fixes

Some games ship a launcher whose menu doesn't start the game correctly on Linux. This fork replaces it during install with one that does. See which games have a fix. Every other game installs exactly as ZOOM built it.

Clean install and detailed uninstall

Each install only creates its own shortcuts. Uninstalling previews what it's about to remove, then displays what happened to each item: Desktop links, menu entries and launch scripts included.

Newer installers

Supports games packaged with Inno Setup 6.3 and newer, thanks to an updated innoextract build.

Older installers

Some older ZOOM installers, like Renoir and Postal, don't have their game's ID inside them, and the official script refuses them. This fork looks the game up in a short list and installs it like any other.

Works on Ubuntu, Debian and Mint

Runs correctly under dash, not only bash, so it works on the default shell of these distros.

Big games split into parts

For installers split across several .bin files, the script looks over the parts before installing. It tells you which one to rename if your browser changed its name, and warns about a part that is missing or cut short.

A specific GE-Proton version per game

A few games only work properly on a certain GE-Proton version, for example when their intros and videos show colour bars, like a TV test pattern, instead of the picture on umu's default Proton. The script downloads that version once while installing, and the game starts offline after that. Other games keep umu's default Proton.

Good to know

What is umu/OWC?

Here is how the Open Wine Components group describes itself:

They're a group of people who work on wine-oriented projects that decided to get together to unify their ideas for the benefit of each other's projects across the board, as well as future projects that may use what they provide.

Does this project use AI?

Yes! AI is used to debug, quickly explain and write most of the code in this fork, but it's strictly controlled. It isn't vibe coded per se (except for this web page).

If you don't feel comfortable with this, you can use the official one.

Does every ZOOM game work?

I believe ZOOM tests their most popular games and submits fixes for many of them. Some work out of the box, some may not work at all. Feel free to submit fixes to umu-protonfixes.

Where do I submit a fix?

General Proton fixes go to umu-protonfixes. A broken launcher, a game that needs a specific GE-Proton version, or an old installer missing from the short list can go in this repo's game-fixes folder.

Can I launch games through Steam?

Depending on your distro, use Steam's "Add a Non-Steam Game..." and pick the game from the list, or right-click the desktop entry and choose "Add to Steam".

I want the official one!

That's ZOOM Platform's own script, zoom-platform.sh, installed with curl zoom-platform.sh | sh.

Do I need Steam installed?

No. OWC forked parts of the Steam Linux Runtime and Proton so they work without Steam.
