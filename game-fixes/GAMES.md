# Games with a fix

Some ZOOM Platform games have a shortcut or launcher that doesn't work correctly on Linux. For these, `zoom-platform.sh`
replaces it automatically during install with one that does — there's nothing to turn on, and every other game installs
exactly as ZOOM built it.

| Game | What's fixed |
| --- | --- |
| Necro Vision - Hardcore Edition | Its launcher menu (the buttons for DirectX 9/10 and the base game/Lost Company) doesn't start the game correctly. It's replaced with four shortcuts that do: DirectX 9 or 10, for the base game or its Lost Company expansion. |

Missing a game you'd expect here? Its own shortcut works fine as-is, or nobody's written a fix for it yet — see
[README.md](README.md) if you'd like to contribute one.
